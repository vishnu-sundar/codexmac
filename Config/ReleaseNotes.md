View available usage limit reset credits in the floating bar’s Resets tab and menu bar dashboard. Each reported credit shows its title and local expiry. Count-only responses and older CLI versions are supported.

Download CodexMac.dmg and drag CodexMac.app into Applications. Requires macOS 14 or later and a Codex CLI signed in with ChatGPT. The universal build is ad-hoc signed and has no Apple notarization. See the README for Gatekeeper and widget setup details. The PNGs show the native views on a clean Mac without account data.
